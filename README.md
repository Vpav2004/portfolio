# Portfolio de Veljko Pavlovic

Décompresse l’archive en conservant ses dossiers, puis ouvre `index.html` dans
ton navigateur. La navigation interne, les pages, les fichiers PDF et la galerie
fonctionnent depuis ces fichiers locaux. Le tableau des compétences utilise
le lecteur PDF du navigateur avec un lien de téléchargement de secours.

## Modifier le site

- Chaque rubrique a son propre fichier HTML à la racine.
- `style.css` contient la navigation, les styles communs et l’adaptation mobile.
- `script.js` gère le menu, les animations et l’agrandissement des galeries.
- `assets/documents/` contient les PDF. `assets/media/` contient les visuels
  et la vidéo de fond. Les textes et les paramètres de disposition de chaque
  section sont modifiables dans son fichier HTML.

## Auto-héberger

Sers le dossier avec ton serveur web. L’URL d’accueil doit pointer sur
`index.html`. Une fois le serveur accessible en HTTPS depuis Internet,
les visiteurs peuvent consulter le portfolio sans compte Wix.
